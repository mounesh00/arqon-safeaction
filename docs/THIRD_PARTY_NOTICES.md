# Third-party material and notice scope

**COMPLETE for identified materials in the current source-only release.**
See [FINAL_RIGHTS_REVIEW.md](FINAL_RIGHTS_REVIEW.md) for owner attestations, exact
material categories, authoritative license sources and the condition matrix.

No dependency implementation/binary, font, upstream dataset or vendored package
is bundled. Requirements, import/type references and lockfile metadata refer to
external packages. No additional copied third-party implementation requiring an
attribution was identified. The two project UI screenshots and Arqon branding have
owner-provided permission attestations. This is not independent legal verification.

THIRD_PARTY_DEPENDENCIES.json preserves dependency license metadata and unknown
entries; it does not relicense packages or replace their full license/NOTICE files.
No fabricated copyright holders, sources, permissions or blanket notices are added.
The original project LICENSE remains intact for owner-authorized project material.

Before distributing installed packages, wheels, compiled browser/server builds,
containers, native/WASM libraries or upstream datasets, review exact included
materials and retain their applicable notices, licenses, attribution, source
availability and relinking requirements. Those future artifacts are not covered
by this source-only review. Reopen the review for any newly identified copied item.
